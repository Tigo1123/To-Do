# مهامي — قائمة المهام اليومية

تطبيق مهام عربي باتجاه RTL، يعمل كتطبيق ويب تقدّمي (PWA)، ويحفظ المهام والتصنيفات في `localStorage` على جهازك فقط. لا يحتاج إلى خادم أو قاعدة بيانات.

## المتطلبات

- Node.js 18 أو أحدث
- npm

## التشغيل محليًا

```bash
npm install
npm run dev
```

افتح عنوان التطوير الذي يظهر في الطرفية. تُحفظ المهام والتصنيفات تلقائيًا في المتصفح، ولا تنتقل إلى جهاز آخر.

## البناء والمعاينة

```bash
npm run build
npm run preview
```

ينتج البناء ملفات الموقع داخل `dist/`، ويتضمن ملف manifest وعامل خدمة للتشغيل دون اتصال. يجب تقديم التطبيق عبر HTTPS لكي تتاح ميزات التثبيت والعمل دون اتصال.

## النشر على Vercel

اربط المستودع بمشروع Vercel، واختر Vite إن لم يُكتشف تلقائيًا. استخدم `npm run build` أمرًا للبناء و`dist` مجلدًا للنشر. لا يحتاج التطبيق إلى إعدادات backend.

## النشر على Netlify

اربط المستودع بموقع Netlify، واضبط أمر البناء على `npm run build` ومجلد النشر على `dist`. يعالج ملف `_redirects` مسارات SPA بإعادة توجيهها إلى `index.html`.

## البيانات والخصوصية

تُحفظ البيانات محليًا في متصفح الجهاز ضمن مفاتيح إصدارية (`mahami.tasks.v1` و`mahami.categories.v1`). حذف بيانات الموقع من المتصفح يحذف نسخة المهام المخزنة عليه.
